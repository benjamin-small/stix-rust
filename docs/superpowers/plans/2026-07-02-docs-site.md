# Docs Site (Stream B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy the mdBook documentation site (guide + Mermaid diagrams + rustdoc under `/api/`) to GitHub Pages via an Actions workflow.

**Architecture:** mdBook sources in `docs/book/` with the `mdbook-mermaid` preprocessor; a `docs.yml` workflow builds the book and `cargo doc --workspace --no-deps`, assembles them into one artifact (`/` = guide, `/api/` = rustdoc), and deploys with `actions/deploy-pages`. Content is drawn from the committed core analysis, the specs, and the binding READMEs.

**Tech Stack:** mdBook + mdbook-mermaid (cargo-installed), GitHub Actions (`deploy-pages`), rustdoc.

**Content sources (read before writing chapters):** the root `README.md`; `bindings/*/README.md`; `docs/superpowers/specs/*.md` (especially the docs-site spec's sharp-edges list and the matcher/custom-models specs); `crates/stix/examples/custom_model.rs`; the crates' lib.rs doc examples.

## Task 6: Deploy workflow + Pages enablement

**Files:**
- Create: `.github/workflows/docs.yml`

- [ ] **Step 1: The workflow** — verbatim:

```yaml
name: docs

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
      - name: Install mdbook + mermaid
        run: cargo install mdbook mdbook-mermaid --locked
      - name: Build book
        run: mdbook build docs/book
      - name: Build API docs
        run: cargo doc --workspace --no-deps
      - name: Assemble site
        run: |
          mkdir -p site
          cp -r docs/book/book/* site/
          mkdir -p site/api
          cp -r target/doc/* site/api/
      - uses: actions/upload-pages-artifact@v3
        with:
          path: site
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

- [ ] **Step 2: Enable Pages (workflow source) once:**

Run: `gh api -X POST repos/benjamin-small/stix-rust/pages -f build_type=workflow 2>/dev/null || gh api -X PUT repos/benjamin-small/stix-rust/pages -f build_type=workflow`
Expected: 201/204 (idempotent across reruns).

- [ ] **Step 3: Final local verification**

Run: `mdbook build docs/book && cargo doc --workspace --no-deps 2>&1 | tail -1`
Expected: both clean.
